# 護膚顧問 App - 韓系溫暖風 🌸

## 🎨 設計風格

**Korean Soft Aesthetic (韓系溫暖風)**

### 配色方案
- **主色調**：柔和粉色 (#E8A4B8) + 薰衣草紫 (#C9B1E8)
- **背景**：奶油白 (#FFFBFD) + 柔粉漸變
- **點綴**：蜜桃色 (#FFD6E0) + 薄荷綠 (#E8F8F0)

### 設計特點
- ✨ 大圓角設計 (16-24px)
- 🌸 柔和漸變效果
- 💕 可愛花瓣飄落動畫
- 🎀 溫暖輕柔陰影
- 🌺 韓系可愛插畫

## 📁 文件結構

```
skincare-app/
```

## 🚀 功能

1. **肌膚測驗** - 5 步驟配對最適合產品
2. **產品搜尋** - 快速查找產品
3. **護膚流程** - 早晚護理建議
4. **AI 分析** - 智能肌膚建議
